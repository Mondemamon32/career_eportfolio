# Raymond Jean L. Bool — Career E-Portfolio

## Files
- `index.html` — main portfolio page
- `css/style.css` — styling and responsive layout
- `js/script.js` — mobile navigation and scroll animations
- `img/` — place your profile photo and project images here

## How to use
1. Open `index.html` in a browser.
2. Replace the `RJB` profile placeholder with your actual photo if desired.
3. Add screenshots/photos/PDF links for your academic work samples.
4. The References/Testimonials and Letters of Recommendation sections are marked TO BE UPDATED and can be filled in when available.
5. Add any additional achievements, projects, certificates, or work samples.

## Included requirements
- Self-introduction
- LinkedIn public profile link
- Resume/education/skills/experience
- Academic work samples
- Business/work/activity experience
- Achievements
- References and recommendation placeholders
- GitHub profile
- Responsive design for desktop and mobile
